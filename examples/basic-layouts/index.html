📐 Layout Algorithm Types

Different approaches to automatically positioning graph elements

🌊 Force Directed

Physics-based layout using repulsive and attractive forces. Creates organic, aesthetically pleasing arrangements where connected nodes are closer together.

📏 Grid Layout

Regular grid-based positioning with consistent spacing. Perfect for structured diagrams and when precise alignment is required.

🏗️ Hierarchical Layout

Tree-based layout organizing nodes by hierarchy levels. Ideal for flowcharts, organizational charts, and process diagrams.

⚡ Automatic Positioning

Algorithms automatically calculate optimal node positions based on connectivity and relationships, eliminating manual layout work.

🎯 Algorithm Selection

Choose the right layout algorithm for your use case - organic, structured, or hierarchical organization.

🔄 Dynamic Updates

Re-layout graphs instantly when structure changes, maintaining visual clarity and readability.

How layout algorithms are implemented in Flow-RS

Layout Algorithm Selection

// Choose layout algorithm based on use case
enum LayoutAlgorithm {
    ForceDirected,  // Organic, physics-based
    Grid,          // Structured, regular spacing
    Hierarchical,  // Tree-based, level organization
}

// Apply layout to graph
match algorithm {
    LayoutAlgorithm::ForceDirected => {
        apply_force_directed_layout(&mut graph);
    }
    LayoutAlgorithm::Grid => {
        apply_grid_layout(&mut graph);
    }
    LayoutAlgorithm::Hierarchical => {
        apply_hierarchical_layout(&mut graph);
    }
}

Force-Directed Layout

// Simplified physics-based layout
fn apply_force_directed_layout(graph: &mut Graph<(), ()>) {
    // Position nodes in initial circle
    for (i, node) in nodes.iter_mut().enumerate() {
        let angle = (i as f64 * 2.0 * PI) / node_count as f64;
        node.position = Position::new(
            center_x + radius * angle.cos(),
            center_y + radius * angle.sin()
        );
    }

    // Apply repulsive and attractive forces
    for _ in 0..iterations {
        apply_repulsive_forces(&mut nodes);
        apply_attractive_forces(&mut nodes);
    }
}

Grid Layout Implementation

// Regular grid positioning
fn apply_grid_layout(graph: &mut Graph<(), ()>) {
    let cols = 3;
    let spacing_x = 250.0;
    let spacing_y = 200.0;

    for (i, node) in nodes.iter_mut().enumerate() {
        let row = i / cols;
        let col = i % cols;

        node.position = Position::new(
            start_x + (col as f64) * spacing_x,
            start_y + (row as f64) * spacing_y
        );
    }
}
