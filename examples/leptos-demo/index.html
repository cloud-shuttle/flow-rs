🚀 Leptos Flow Demo

This demo showcases the Leptos Flow editor with the following features:

  • Drag & Drop: Click and drag nodes to move them around
  • Edge Connections: Edges automatically connect nodes with smooth curves
  • Viewport Controls: Pan and zoom the canvas
  • Real-time Rendering: Canvas2D renderer with performance stats
  • Interactive Controls: Add nodes, clear graph, and create connections
