Flow-RS Hello World

The simplest flow diagram using Rust & WebAssembly

What you're seeing:

A basic flow diagram with 3 nodes connected by 2 edges, rendered using Flow-RS's Canvas2D renderer.

Key features demonstrated:

  • Simple node and edge creation
  • Canvas2D rendering
  • WebAssembly integration
  • Minimal setup code

Code:

// Create nodes let start = Node::simple("start", Position::new(150.0, 150.0)); let process = Node::simple("process", Position::new(400.0, 150.0)); let end = Node::simple("end", Position::new(650.0, 150.0)); // Create edges let edge1 = Edge::simple("flow1", "start", "process"); let edge2 = Edge::simple("flow2", "process", "end"); // Render renderer.render_graph_dyn(&graph, &viewport)?;
