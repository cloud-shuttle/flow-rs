🎨 Interactive Node Components

Custom node types with specialized rendering, behaviors, and user interactions

🔘

Button Nodes

Clickable buttons that trigger actions. The "Click Me!" button randomizes other node values, while "Reset" restores defaults.

🎚️

Slider Nodes

Interactive sliders for value control. Drag the handle to adjust values from 0-100%. Shows current percentage.

📊

Progress Nodes

Animated progress bars that continuously update. Demonstrates real-time value changes and smooth animations.

🔄

Toggle Nodes

On/off switches with smooth animations. Click to toggle between active/inactive states with visual feedback.

📈

Data Display Nodes

Information displays that show dynamic data. Updates periodically to simulate real-time monitoring.

🎯 Interaction Guide

  • Hover Effects: Move your mouse over nodes to see hover states and color changes
  • Button Clicks: Click buttons to trigger actions - "Click Me!" randomizes values, "Reset" restores defaults
  • Slider Control: Click and drag slider handles to adjust values in real-time
  • Toggle Switches: Click toggles to switch between on/off states with smooth animations
  • Add Nodes: Use the controls above to add new custom nodes of different types
  • Visual Feedback: Watch for color changes, animations, and value updates as you interact
  • Real-time Updates: Progress bars and data displays update automatically
